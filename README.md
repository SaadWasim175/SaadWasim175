## My technology stack
Like many people, I started out with writing code in python back in 6th grade. Later on, I got interested in learning about the underlying workings and functionalities of software, which is why I got into C, mastered its manual memory allocation, then fell in love with Rust, which lets me not have to worry about null pointers, buffer overflows and many other errors which plagued me in C. I have also begun using Rust for embedded programming on my microcontrollers, for the same reasons as mentioned before, i.e, memory safety, compile time rule enforcement to point out bugs early etc.
